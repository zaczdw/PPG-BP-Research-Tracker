## Integrating biophysical dynamics with a data-driven method for blood pressure estimation using photoplethysmography

- 版本年份：2026（Crossref 近似题名与 DOI 核验）
- 来源：[Biomedical Signal Processing and Control](https://doi.org/10.1016/j.bspc.2026.110445)；DOI: 10.1016/j.bspc.2026.110445
- 这篇做了什么：把 Windkessel 血流动力学约束加入 PPG→BP，比较其对跨人与个体化场景的帮助。
- 方法：LSTM 数据驱动分支与 three-element Windkessel ODE 约束组成 PINN；跨人采用 leave-one-subject-out，个体化模拟 ICU→ambulatory 并严格时间分离。
- 结果：跨人时 SBP MAE 17.56→13.86 mmHg（改善 21.07%），DBP 10.47→9.55（8.79%）；个体化场景与普通 baseline 相当，无显著优势。
- 结论：物理约束改善跨人结果但误差仍高，在已有个人数据时并未证明额外收益。
- 数据库判断：PINN 不是自动提高精度的保证；当前跨人误差离部署仍远。
- 校准：not reported；可得摘要/正文信息未报告个人 cuff calibration。
- Subject split：是；跨人采用 leave-one-subject-out，个体化采用严格时间分离。
- External validation：否；未确认独立外部队列验证。
- 推理所需输入：PPG
- 可部署性：研究验证阶段；跨人推理可 PPG-only；个体化版本需要历史个人 PPG+BP 校准，不需当前 BP。
- ABP/BP 泄露审查：LOSO 与严格时间分离降低 window/subject leakage；未见当前 BP 反归一化，风险较低。
- 审计状态：已完成重点审核

## LAST-CBPM: photoplethysmography-based quasi-continuous blood pressure monitoring algorithm

- 版本年份：2026（Crossref 精确题名/年份与可得 primary abstract/full text 核验）
- 来源：[Biomedical Signal Processing and Control](https://doi.org/10.1016/j.bspc.2026.109723)；DOI: 10.1016/j.bspc.2026.109723
- 这篇做了什么：用单通道 PPG 做 quasi-continuous BP，并通过 subject-specific calibration 适应真实可穿戴域。
- 方法：Daubechies-6 wavelet 去噪，temporal self-attention+BiLSTM 做群体估计，再用 ST-ResNet 和静息 baseline BP 做个人校准。
- 结果：MIMIC-IV SBP/DBP MAE 2.73±2.17/2.16±2.35 mmHg；自建 RTW-CV 88 人、10,754 分钟上为 4.87±5.89/4.52±4.38，论文称达到 AAMI/BHS Grade A/IEEE-SA。
- 结论：外部可穿戴结果优于很多纯医院模型，但依赖个人静息 BP，且摘要未证明完整器械标准协议。
- 数据库判断：是有现实域验证的校准型方案，不是 calibration-free。
- 校准：resting baseline BP；静息 baseline BP 用于 ST-ResNet 个体校准。
- Subject split：未报告；可得来源未明确证明 subject-disjoint；已按未知项保留，不视为通过。
- External validation：是；自建 RTW-CV 可穿戴队列
- 推理所需输入：PPG、stored baseline BP/personal parameters
- 可部署性：有条件可部署；推理需单通道 PPG 和已保存的个人静息 baseline BP；当前时刻无需 cuff BP。
- ABP/BP 泄露审查：历史 baseline 属 target-dependent calibration；当前 BP 未进入推理。subject split 未在摘要明确，风险中等。
- 审计状态：已完成重点审核

## Calibration-based continuous blood pressure estimation using pulse-derived signals and feature normalization

- 版本年份：2025 预印本 / 2026 期刊（Elsevier 期刊文章核验）
- 来源：[Biomedical Signal Processing and Control](https://doi.org/10.1016/j.bspc.2026.109852)；DOI: 10.1016/j.bspc.2026.109852
- 这篇做了什么：融合 PPG、VPPG、APPG 的多阶脉搏形态，并用参考 BP 校准连续 SBP/DBP。
- 方法：三个 CNN encoder 提取 PPG 及一、二阶导数特征，以无参数 affine transformation 注入 BP 信息，再用带 squeeze-excitation 的 RBSE block 回归。
- 结果：在 VitalDB 与 BP-UCI 上优于论文比较的 baseline，并声称满足 AAMI、BHS Grade A；可得摘要未给可独立核对的完整 MAE 表。
- 结论：多阶导数和校准可能提高同域结果，但 BP normalization/reference 的使用边界决定是否可部署。
- 数据库判断：必须把参考 BP 是历史校准值还是测试当前值写清楚；在此之前不能按免校准模型解读。
- 校准：reference-BP calibration；BP normalization/affine calibration 的边界需结合全文流程理解。
- Subject split：未报告；可得来源未明确证明 subject-disjoint；已按未知项保留，不视为通过。
- External validation：否；未确认独立外部队列验证。
- 推理所需输入：PPG/VPPG/APPG、stored reference-BP calibration
- 可部署性：有条件可部署；至少需要 PPG 和历史 reference BP/normalization 参数；当前参考 BP 是否完全不参与尚需方法图逐步复核。
- ABP/BP 泄露审查：存在 target-dependent calibration；未发现明确逐窗真实 BP 反归一化证据，但摘要不足以排除，风险中高。
- 审计状态：已完成重点审核

## Personalized Calibration and Hybrid Feature Fusion for Continuous Blood Pressure Estimation Using PPG and ECG Signals

- 版本年份：2026（Crossref 精确题名/年份与可得 primary abstract/full text 核验）
- 来源：[Sensors](https://doi.org/10.3390/s26154676)；DOI: 10.3390/s26154676
- 这篇做了什么：在小样本条件下融合手工生理特征、自监督波形表示和个人 baseline BP。
- 方法：从 ECG/PPG 提取 PTT、HRV、PPG morphology，并用 masked reconstruction encoder 学 embedding；把最早 calibration file 的 base BP 通过 alpha-weighted 策略加入 XGBoost。
- 结果：私有数据与 BP-UCI 的 SBP/DBP MAE 分别为 7.25/3.98 和 7.85/4.02 mmHg；作者仅表述为当前实验下的方法可行性。
- 结论：个体 baseline 有帮助，但 SBP 仍偏高，且需要更大、更丰富队列。
- 数据库判断：这是明确的个体校准模型，成绩不能与免校准或 subject-independent 方法直接比较。
- 校准：personal baseline BP；使用个人最早 calibration file 的 base BP。
- Subject split：未报告；可得来源未明确证明 subject-disjoint；已按未知项保留，不视为通过。
- External validation：否；未确认独立外部队列验证。
- 推理所需输入：PPG、ECG、stored personal base BP
- 可部署性：有条件可部署；推理需 ECG+PPG、已保存的个人 base BP 和模型特征；当前 BP 不需要。
- ABP/BP 泄露审查：最早文件作校准可避免当前目标直接输入，但校准/测试文件与 subject split 细节未充分报告，风险中等。
- 审计状态：已完成重点审核
