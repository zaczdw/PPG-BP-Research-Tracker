## Domain-independent PPG signal quality assessment framework via representation learning

- 版本年份：2026（此前重点深审记录）
- 来源：[Scientific Reports](https://www.nature.com/articles/s41598-026-58783-6)；DOI: 10.1038/s41598-026-58783-6
- 这篇做了什么：建立跨部位、跨设备更稳健的 PPG signal quality assessment，先识别坏信号再进入 BP 或其他下游模型。
- 方法：用 triplet loss 微调预训练 PPG Transformer，以待测片段到高质量 reference embedding 的距离判断质量。
- 结果：F1 约为手指 90%、手腕 95%、颈部 70%；跨域效果因采集部位而异。
- 结论：SQA 可实时运行且不依赖 BP 标签，适合作为部署前端；颈部等新域仍需更多数据。
- 数据库判断：先判断 PPG 能不能用，再估 BP；这是减少运动伪影失败的实用组件。
- 校准：reference-embedding set；No BP calibration; reference embeddings define signal-quality score.
- Subject split：未报告；Exact subject partition details need table-level audit.
- External validation：是；wrist and neck datasets
- 推理所需输入：PPG、stored high-quality reference embeddings
- 可部署性：适合作为 BP 模型前置 SQA；推理仅需 PPG 和已保存的高质量 reference embedding，不需要当前 BP。
- ABP/BP 泄露审查：未使用 BP 目标做质量筛选，目标泄露风险低；应继续避免同一受试者片段跨训练/测试。
- 审计状态：已完成重点审核

## Large-scale bilateral cardiovascular monitoring via wearable rings

- 版本年份：2026（此前重点深审记录）
- 来源：[npj Digital Medicine](https://pubmed.ncbi.nlm.nih.gov/42477400/)；DOI: 10.1038/s41746-026-03036-z
- 这篇做了什么：检验左右手双 ring PPG 是否比单侧信号更适合预测 BP 等心血管和人口学指标。
- 方法：在 12 种 backbone 上比较左手、右手、双侧融合和平均 ring PPG 的多目标预测。
- 结果：1,810 人、97,559 个有效样本；双侧 SBP/DBP MAE 为 12.36/8.21 mmHg，只比人群均值 baseline 13.81/9.27 略好。
- 结论：双侧信号有一定增益，但绝对 BP 误差仍大，且双 ring 的硬件成本并未换来决定性提升。
- 数据库判断：更适合作为左右差异和姿势研究资源，不宜宣传为高精度 BP 方案。
- 校准：none reported；Population benchmark.
- Subject split：未报告；Do not assume session-level split is safe.
- External validation：否；Single benchmark cohort.
- 推理所需输入：bilateral ring PPG
- 可部署性：HR 价值较强，绝对 BP 价值有限；需要两枚 ring，是额外佩戴成本；当前 BP 精度不足以支撑产品结论。
- ABP/BP 泄露审查：必须按参与者划分；若把同一人的左右手或不同 session 分到训练和测试，会显著高估泛化。
- 审计状态：已完成重点审核

## Photoplethysmography for Heart Rate and Rhythm Monitoring: Current Evidence and Clinical Applications

- 版本年份：2026（JACC 正式文章核验）
- 来源：[JACC: Clinical Electrophysiology](https://doi.org/10.1016/j.jacep.2026.06.034)；DOI: 10.1016/j.jacep.2026.06.034
- 这篇做了什么：总结 PPG 在 HR 和 rhythm monitoring 中的当前证据、应用与限制。
- 方法：state-of-the-art review，覆盖 pulse-rate 测量、AF screening、wearable/remote monitoring 与常见 confounder。
- 结果：多项研究显示 HR 较准确、AF screening 有较高 sensitivity/specificity；motion、skin tone 和高 HR 时脉搏幅度下降会影响质量。
- 结论：PPG 适合筛查和远程监测，但 arrhythmia 诊断仍需要 ECG 确认。
- 数据库判断：PPG 是 screening signal，不应替代诊断级 ECG；本综述也不是 BP 验证。
- 校准：not applicable；该研究不是连续 BP estimator。
- Subject split：未报告；可得来源未明确证明 subject-disjoint；已按未知项保留，不视为通过。
- External validation：否；未确认独立外部队列验证。
- 推理所需输入：PPG
- 可部署性：非 BP 测量任务；需 PPG 和 signal-quality control；异常 rhythm 应转 ECG confirmation。
- ABP/BP 泄露审查：综述无训练/测试泄露；核心风险是质量伪影与把筛查阳性当确诊。
- 审计状态：已完成重点审核
