## Domain-independent PPG signal quality assessment framework via representation learning

- 来源：[Scientific Reports](https://www.nature.com/articles/s41598-026-58783-6)
- 主题：PPG、signal quality、representation learning、domain generalization
- 数据集：CSL finger PPG、WCS wrist PPG、AA neck PPG
- 输入：PPG
- 方法：Fine-tunes a pretrained PPG Transformer with triplet loss; quality is embedding distance to high-quality reference embeddings.
- 主要结果：Approximate F1: 90% finger, 95% wrist with generalized references, 70% neck.
- 校准：reference-embedding set；No BP calibration; reference embeddings define signal-quality score.
- Subject split：reported evaluation across datasets；Exact subject partition details need table-level audit.
- External validation：true；Cross-location generalization is central.
- 可部署性：适合作为 BP 模型前置 SQA（deployable-front-end）
- 推理输入：PPG、stored high-quality reference embeddings
- 泄露风险：low for BP target leakage；If used in BP studies, freeze SQA before test evaluation and avoid tuning thresholds on test BP error.
- 审计状态：priority-reviewed

## Large-scale bilateral cardiovascular monitoring via wearable rings

- 来源：[npj Digital Medicine](https://pubmed.ncbi.nlm.nih.gov/42477400/)
- 主题：PPG、ring、bilateral、cuffless BP、benchmark
- 数据集：MAIBO-derived bilateral benchmark
- 输入：left ring PPG、right ring PPG
- 方法：Twelve backbones benchmark bilateral and averaged ring-PPG prediction across cardiovascular/demographic targets.
- 主要结果：97,559 valid samples from 1,810 participants; bilateral SBP/DBP MAE 12.36/8.21 mmHg, only modestly better than cohort-mean baselines 13.81/9.27.
- 校准：none reported；Population benchmark.
- Subject split：needs full-method verification；Do not assume session-level split is safe.
- External validation：false；Single benchmark cohort.
- 可部署性：HR 价值较强，绝对 BP 价值有限（limited-for-BP）
- 推理输入：bilateral ring PPG
- 泄露风险：medium；Transparent weak BP result is more credible than near-zero MAE under unsafe splits.
- 审计状态：priority-reviewed
