## 1. Estimating Changes in Systolic Blood Pressure Based on Pulse Wave Morphology Using Paired Segment Comparison

- 来源：[Physiological Measurement](https://pubmed.ncbi.nlm.nih.gov/42320511/)；DOI: 10.1088/1361-6579/ae7fea
- 方法：将绝对 SBP 回归改写为两段 20 秒 PPG 之间的 ΔSBP 估计，在 VitalDB 和 MIMIC-III 的 12,279 名患者上开发并保留 2,457 名患者测试。
- 结果：VitalDB/MIMIC-III 的 ΔSBP RMSE 为 14.53/11.37 mmHg，r 为 0.79/0.65，Cohen's κ 为 0.57/0.44；最长分析覆盖 28 小时。
- 判断：这是 ΔSBP 模型；不能把其结果表述为免校准绝对血压。

## 2. Smartphone-Based Blood Pressure Monitoring via the Oscillometric Finger Pressing Method: Investigation of the DC Component of PPG

- 来源：[IEEE Transactions on Biomedical Engineering](https://pubmed.ncbi.nlm.nih.gov/41247889/)；DOI: 10.1109/TBME.2025.3633555
- 方法：让用户按视觉提示逐渐增加手指压力，以 PPG-force 传感单元记录总 PPG 和压力；用动脉顺应性/组织压缩模型定位 DC PPG 弯折点估计臂部 SBP。
- 结果：对 18 名志愿者，估计 SBP 与 cuff SBP 的相关系数为 0.90，precision error 为 9.2 mmHg。
- 判断：这是主动按压式测量，不是仅靠相机 PPG 的无感连续 BP。

## 3. Interpretable Photoplethysmography-Based Machine-Learning Model for Noninvasive Assessment of Systolic Blood Pressure

- 来源：[Frontiers in Physiology](https://pubmed.ncbi.nlm.nih.gov/42305919/)；DOI: 10.3389/fphys.2026.1779262
- 方法：从 90 秒指端 PPG 提取形态和频域特征，加年龄、BMI，用 LASSO logistic regression 与五折交叉验证分类 SBP 状态，并以 SHAP 解释。
- 结果：AUC 0.83（95% CI 0.79-0.87）、F1 0.83、Cohen's d 1.39；最终保留年龄、BMI、P1、波形尖锐度和 H2/H1。
- 判断：AUC/F1 是分类指标，不能与 SBP/DBP MAE 直接比较。

## 4. A Multimodal Learning Framework for Detecting Systemic Hypertension in Sleep Apnea Patients Using ECG and PPG Signals

- 来源：[IEEE Journal of Biomedical and Health Informatics](https://pubmed.ncbi.nlm.nih.gov/42154719/)；DOI: 10.1109/JBHI.2026.3694833
- 方法：FusionNet 以 multiple-instance learning 汇总整夜 PSG，门控融合 ECG/PPG，并加入 HRV/PRV、睡眠阶段和呼吸暂停事件；采用 leave-one-patient-out。
- 结果：AUROC 87.34%、准确率 79.03%、特异度 81.25%、MCC 0.5801。
- 判断：这是高血压分类，不是逐搏或连续 BP 估计。

## 5. GHC-Net: A Gramian Angular Field-Based Hybrid CNN for Cuffless Blood Pressure Classification Using PPG Signals

- 来源：[Computers in Biology and Medicine](https://pubmed.ncbi.nlm.nih.gov/41833169/)；DOI: 10.1016/j.compbiomed.2026.111622
- 方法：把一维 PPG 编码为 GAF 二维矩阵，使用含 hybrid dilated convolution 和 channel attention 的 GHC-Net 做正常/高正常/高血压三分类。
- 结果：PPG-BP 公共集准确率 76.39%、F1 76.68%；私有集准确率 92.66%、F1 93.33%。
- 判断：分类准确率不能当作 mmHg 精度；subject split 是首要复核点。
